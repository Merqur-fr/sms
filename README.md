# SMS de rappel · Merqur

Page publique qui ouvre l app SMS du téléphone avec un numéro et un texte déjà remplis, pour les rappels de démos envoyés dans Slack par le bot Merqur Reporting.

Lien : `https://merqur-fr.github.io/sms/#<numéro encodé>/<texte encodé>`. Le numéro et le texte sont après le `#` : ils ne sont jamais envoyés au serveur. Aucun script externe, aucun traceur.
